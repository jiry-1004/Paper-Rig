# PaperRig
パーツ分けしたイラスト（PSD）1枚から、歩く・ジャンプなどのアニメーションを、コマを描き足さずに作れるUnityエディタ拡張です。


## なぜ作ったか
[2Dのアニメは動きごとにコマを何枚も描く必要があり、手間がかかると感じた体験]

## できること
- レイヤー名からパーツ（頭・体・腕・脚）を判別して、骨を自動で入れる
- 待機・歩く・ジャンプ・手をふる をボタン1つで作る
- 「両手を上げて喜ぶ」のように文章で書くと、AI（Claude）がモーションを作る
- モーションを、コマを並べた画像（スプライトシート）に書き出す
- ずれた関節は、絵を動かさずにドラッグで修正
- 横向きのキャラに、ダッシュ・ジャンプ・攻撃・やられなど13の動きをAIなしで付け、ゲームのコードから動かせる
- 完成したキャラを .unitypackage に書き出して、別のプロジェクトでそのまま使える
