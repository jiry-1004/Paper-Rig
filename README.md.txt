# PaperRig

パーツ分けしたイラスト（PSD）1枚から、歩く・ジャンプなどのアニメーションを、コマを描き足さずに作れるUnityのツールです。

![デモ](docs/demo.gif)

## なぜ作ったか

[2Dのアニメは動きごとにコマを何枚も描く必要があり、手間がかかると感じた体験を1〜2文で]

## できること

- レイヤー名からパーツ（頭・体・腕・脚）を見分けて、骨を自動で入れる
- 待機・歩く・ジャンプ・手をふる の動きを、ボタン1つで作る
- 「両手を上げて喜ぶ」のように文章で書くと、AI（Claude）が動きを作る
- 動きを、コマを並べた画像（スプライトシート）に書き出す
- ずれた関節は、絵を動かさずにドラッグで直せる

## 動作環境

- Unity 6.3 LTS（テンプレートは Universal 2D）
- 2D PSD Importer（Universal 2D テンプレートに最初から入っています）
- PSDで保存できるお絵描きソフト（CLIP STUDIO PAINT、Krita、Photopea、Photoshop など）
- AIで動きを作るときだけ、Claude の APIキー

## 使い方

Unityをはじめて触る人でもできるように、順番に書いています。上から1つずつ進めてください。

### 0. Unityの画面の名前

この先は、Unityの画面をこの名前で呼びます。

| 名前 | 場所（最初の配置） | 何をするところ |
| --- | --- | --- |
| Project ウィンドウ | 下 | 絵や動きなどのファイルが並ぶ |
| Hierarchy（ヒエラルキー） | 左 | シーンに置いたものが並ぶ |
| Scene ビュー | 真ん中 | 置いたものを見たり動かしたりする |
| Game ビュー | 真ん中（Scene の隣のタブ） | ▶を押したときのゲーム画面 |
| Inspector（インスペクター） | 右 | 選んだものの設定を変える |
| Console | 下（Project の隣のタブ） | エラーが出る |
| ▶（再生ボタン） | 上の真ん中 | 押すとゲームが動く。もう一度押すと止まる |

ウィンドウが見当たらないときは、上のメニューの「Window」→「General」から開けます。

### 1. Unityのプロジェクトを作る

1. Unity Hub と Unity 6.3 LTS をインストールする。学生や個人の趣味なら、無料の Unity Personal で使えます
2. Unity Hub の「Projects」→「New project」を押す
3. 上の Editor Version が 6.3 LTS になっていることを確認し、テンプレートは「Universal 2D」を選ぶ
4. Project name を決める。保存場所は `C:\Dev` のように、日本語やスペースが入らないフォルダにする（エラーを防ぐため）
5. 「Create project」を押して、Unityが開くまで待つ

すでにあるプロジェクトに入れる場合は、Universal 2D テンプレートで作ったプロジェクトにしてください。

### 2. PaperRig を入れる

1. このページ右側の「Releases」から、`PaperRig.unitypackage` をダウンロードする
2. Unity を開いたまま、ダウンロードしたファイルをダブルクリックする（または、上のメニューの「Assets」→「Import Package」→「Custom Package...」で選ぶ）
3. ファイルの一覧が出るので、全部チェックが入ったまま「Import」を押す
4. 上のメニューに「Tools」→「PaperRig」が出れば成功です

出てこないときは、Console に赤いエラーが出ていないか確認してください（下の「うまくいかないとき」）。

### 3. 絵を描く

最初は、丸と四角で描いた棒人間で試すのがおすすめです。うまく動いてから、自分の絵で試します。

**描き方のルール**

- 正面向きで描く。腕は体の横に下ろすか、横にまっすぐ伸ばす（斜めの腕は関節がずれやすい）
- パーツごとにレイヤーを分ける。レイヤー1枚が、動かせるパーツ1つになる
- 少なくても「頭・体・腕×2・脚×2」に分ける。理想は、腕を「上腕・前腕・手」、脚を「太もも・すね・足先」の3つずつに分けること
- 肩・ひじ・ひざのつなぎ目は、パーツどうしを少し重ねて、端を丸く描く。回したときにすき間が出なくなる
- グループ（フォルダ）は使わない。すべてのレイヤーを表示した状態で保存する
- 白い背景や「用紙」のレイヤーは消す。パーツの外側は透明にする
- 絵の大きさは、高さ1000〜2000ピクセルくらい

**レイヤー名のルール**

レイヤー名に下の言葉が入っていれば、パーツを見分けます。左右は位置から自動で決めるので、名前に「左」「右」はいりません。「前腕の袖」のような名前でも大丈夫です。

| パーツ | 日本語の名前の例 | 英語の名前の例 |
| --- | --- | --- |
| 頭 | 頭、顔、髪、目、口、眉、帽子 | head, face, hair, eye, mouth |
| 体 | 体、胴、胸、腰 | body, torso, chest |
| 上腕 | 上腕（腕が1枚なら「腕」） | upperarm（または arm） |
| 前腕 | 前腕 | lowerarm, forearm |
| 手 | 手 | hand |
| 太もも | 太もも（脚が1枚なら「脚」） | upperleg, thigh（または leg） |
| すね | すね | lowerleg, shin |
| 足先 | 足先、靴 | foot, shoe |

どれにも当てはまらない名前（リボン、ネクタイなど）は、重なっているパーツと一緒に動きます。頭の上のリボンなら、頭と一緒に動きます。

**PSDで保存する方法**

- CLIP STUDIO PAINT：「ファイル」→「複製を保存」→「.psd（Photoshopドキュメント）」
- Krita：「ファイル」→「名前を付けて保存」で、ファイルの種類を PSD にする
- Photopea：「File」→「Save as PSD」
- Photoshop：保存するときに「互換性を最大に」をオンにする

PSDの名前は、キャラごとに違う名前にしてください。同じ名前だと、作った動きが別のキャラと混ざります。

### 4. 絵をUnityに入れる

1. Project ウィンドウの「Assets」を右クリック →「Create」→「Folder」で、`Characters` などのフォルダを作る
2. エクスプローラー（Macは Finder）から、PSDをそのフォルダにドラッグ＆ドロップする
3. Project ウィンドウでPSDをクリックし、右の Inspector を見る
4. Inspector のいちばん上にある「Importer」のプルダウンを、`UnityEditor.U2D.PSD.PSDImporter` に変える（拡張子が .psb ならこの手順はいらない）
5. 次のように設定する。ほかはそのままでOK
   - Texture Type：Sprite (2D and UI)
   - Sprite Mode：Multiple
   - Import Mode：Individual Sprites (Mosaic)
   - Character Rig の **Use as Rig にチェック**（「Character Rig」の左の▶を押すと開く）
   - Use Layer Group：チェックなしのまま
6. Inspector 右下の「Apply」を押す。灰色で押せないときは、もうその設定になっているので次へ進んでOK
7. Project ウィンドウのPSDを、Hierarchy にドラッグする。Scene ビューにキャラが出れば成功

**確認**：Hierarchy でキャラの左の▶を押して開き、レイヤーの名前が並んでいればOKです。1つしかないときは、レイヤーが分かれていないか、Use as Rig のチェックを忘れています。

キャラが見えないときは、Hierarchy でキャラをダブルクリックすると、Scene ビューがキャラの位置に移ります。マウスホイールで拡大・縮小できます。

絵を直したいときは、お絵描きソフトで同じPSDに上書き保存します。PSDの場所は、Project ウィンドウでPSDを右クリック →「Show in Explorer」（Macは「Reveal in Finder」）で開けます。上書きすると、Unityが自動で読み直します。

### 5. 骨を入れる

1. 上のメニューの「Tools」→「PaperRig」→「1. リグを作る」を押す。ウィンドウが開く
2. Hierarchy で、さっき置いたキャラ（いちばん上の親）をクリックする。ウィンドウの「選択中」にキャラの名前が出る
3. 「プレハブとして保存」にチェックを入れておく（作ったキャラがファイルとして残る）
4. 「① パーツ判別を確認」を押す。下に、レイヤーごとのパーツの種類が出る。違っていたら、お絵描きソフトでレイヤー名を直して上書き保存し、もう一度押す
5. 「② リグを作る」を押す。元のキャラは隠れて、`○○_Rig` という新しいキャラができる
6. Scene ビューに、関節のオレンジの丸と骨の線が出ていれば成功

**動くか試す**：Hierarchy で `○○_Rig` の▶を開き、骨（例：Hip → Body → UpperArm_R）をクリックします。Inspector の Transform にある Rotation の Z に 45 と入れると、その先のパーツが一緒に回ります。試したら Ctrl+Z（Macは Cmd+Z）で戻します。

Scene ビューで絵をクリックすると、キャラ全体が選ばれます。骨は Hierarchy から選んでください。

**関節の位置がずれていたら**

1. Hierarchy で、ずれている骨（例：`LowerArm_L`）をクリックする
2. Inspector の「関節の位置を直す：OFF」を押して ON にする
3. Scene ビューのオレンジの丸をドラッグする。絵はそのままで、関節だけが動く
4. 終わったら OFF に戻す

失敗しても Ctrl+Z で元に戻せます。

### 6. 動きを作る

1. 「Tools」→「PaperRig」→「2. モーションを作る」を押す
2. Hierarchy で `○○_Rig` をクリックする
3. 作りたい動きにチェックを入れる（待機・歩く・ジャンプ・手をふる）
4. 「モーションを作る」を押す
5. 上の真ん中の ▶ を押す。Game ビューでキャラが待機の動きを始める
6. Game ビューの左上のボタンで、Walk・Jump・Wave に切り替えられる
7. もう一度 ▶ を押すと止まる

▶を押している間に変えた設定は、止めると元に戻ります。設定は止めてから変えてください。

**保存する**

- Ctrl+S（Macは Cmd+S）でシーンを保存する
- 手順5で「プレハブとして保存」にチェックを入れた場合は、Hierarchy で `○○_Rig` を選び、Inspector 上部の「Overrides」→「Apply All」を押す。動きがプレハブにも入る

### 7. 文章で動きを作る（AI・使わなくてもOK）

**準備（はじめの1回だけ）**

1. [Claude Console](https://platform.claude.com/settings/keys) でアカウントを作り、「Create Key」でAPIキーを作ってコピーする
2. 支払い設定でクレジットを購入する。1回の生成は数円もかからない目安なので、心配なら最小額で大丈夫
3. APIキーは人に見せない。GitHub などにも上げない

**使い方**

1. 「Tools」→「PaperRig」→「3. AIで動きを作る」を押す
2. Hierarchy で `○○_Rig` をクリックする
3. 「APIキー」にキーを貼る。キーはこのPCの中だけに保存されるので、次からは入れなくていい
4. 「どんな動き？」に、作りたい動きを文章で書く（例：両手を上げて、ぴょんぴょん跳ねて喜ぶ）
5. 「長さ（秒）」と「くり返す」を決めて、「AIでモーションを作る」を押す
6. 数秒で `AI_○○` という動きができる。▶を押し、左上のボタンで再生する

変な動きになったら、「右手を真上にまっすぐ上げる」「ゆっくり」のように、具体的に書き直して作り直します。

### 8. コマの画像に書き出す

1. 「Tools」→「PaperRig」→「4. コマに書き出す」を押す
2. Hierarchy で `○○_Rig` をクリックする
3. 「モーション」で動きを選び、「コマ数」と「1コマの大きさ」を決める。歩きなら8コマ、ジャンプなら10〜12コマが目安
4. 「PNGに書き出す」を押す
5. Project ウィンドウの `Assets/PaperRig/Output` に、`○○_Walk_8f.png` のような画像ができる

コマは左上から右へ並び、行の端まで来たら次の行に続きます。背景は透明です。

**Unityでコマ送りのアニメにする**

1. Project ウィンドウでPNGをクリックし、Inspector の Sprite Mode を Multiple にして「Apply」
2. Inspector の「Open Sprite Editor」を押す
3. 左上の「Slice」→ Type を「Grid By Cell Size」にし、Pixel Size に書き出したときの「1コマの大きさ」を入れて「Slice」→ 右上の「Apply」
4. Project ウィンドウでPNGの▶を開き、中のコマを全部選んで（最初をクリック → Shift を押しながら最後をクリック）、Scene ビューにドラッグする
5. 保存する名前を聞かれるので、名前を付けて保存する。アニメーションが付いたキャラができる

**Unity以外のツールで使う**

PNGを右クリック →「Show in Explorer」（Macは「Reveal in Finder」）でフォルダを開き、PNGをコピーして使います。

### 作ったキャラをほかのプロジェクトで使う

1. Project ウィンドウで `Assets/PaperRig/Output` フォルダを右クリック →「Export Package」
2. 「Include dependencies」にチェックが入っていることを確認して、「Export」を押す。絵（PSD）と、動かすためのスクリプトも一緒に入る
3. 使う側のプロジェクト（Universal 2D）で、できたファイルをダブルクリック →「Import」
4. `Output` の中のキャラ（プレハブ）を Hierarchy にドラッグする

## うまくいかないとき

| 症状 | 原因と対処 |
| --- | --- |
| メニューに Tools > PaperRig が出ない | Console に赤いエラーが残っている。Universal 2D テンプレートのプロジェクトか確認する |
| PSDを置くと1枚の絵になる／「パーツの絵が見つかりません」 | Importer の切り替え忘れか、Use as Rig のチェック忘れ（手順4） |
| 全部「体」になる | レイヤー名がルールに合っていない。「① パーツ判別を確認」で見て、名前を直す |
| 関節が変な場所にある | 斜めのパーツは苦手。「関節の位置を直す」で手で直す |
| 回すとパーツの間にすき間ができる | つなぎ目の重なりが足りない。端を丸くして、少し重ねて描き直す |
| ▶を押しても動かない | `○○_Rig` を選んで「モーションを作る」をもう一度押す |
| 「骨『LowerArm_L』がこのキャラにない」と出る | 絵にそのパーツがないだけなので問題なし |
| AIで401エラー | APIキーが違う。コピーし直して貼る |
| AIでクレジット不足のエラー | Claude Console でクレジットを購入する |
